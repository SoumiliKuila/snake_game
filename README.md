🐍 Snake Game

A simple and interactive Snake Game built using HTML, CSS, and JavaScript.

The game is designed to work directly in a web browser and is mobile-friendly, so it can be played on both desktop and smartphone.

🎮 Live Demo

Play the game:
https://soumilikuila.github.io/snake-game/

✨ Features

- 🐍 Classic Snake gameplay
- 🍎 Random food generation
- 🏆 Score tracking
- ⭐ Best score saved using Local Storage
- 💥 Game-over detection
- ⌨️ Keyboard controls
- 📱 Mobile touch controls
- 🔄 Restart game option
- 📱 Responsive design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas
- Local Storage

🎮 Controls

Desktop

- ⬆️ Arrow Up / W — Move Up
- ⬇️ Arrow Down / S — Move Down
- ⬅️ Arrow Left / A — Move Left
- ➡️ Arrow Right / D — Move Right

Mobile

Use the on-screen arrow buttons to control the snake.

🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Click Start Game.
5. Start playing! 🎮

📱 Browser Support

- Firefox
- Safari

It is also designed to work on mobile browsers.
